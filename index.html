Variables are names.
Objects hold the data.

Python code becomes easier when you picture what happens behind each assignment. A variable name is a label that refers to an object. That object has a value and a type.

What does a variable do?

student_name = "Ayesha"
score = 95

Python creates objects for the values, then binds the names student_name and score to them. A variable is not a box containing a value; it is a name bound to an object.

student_name→"Ayesha" · str
score→95 · int

Think of labels on objects

Imagine name tags placed beside objects. The tag is the variable name, while the object is the actual value in memory. Multiple names can refer to the same object.

first↘42 · int↗second
Remember: variable name → object → value and type. The arrow represents a reference/binding, not a copy by default.
01 · Assignment & reassignment

Assign a name.
Then reassign it.

The equals sign (=) in Python means assignment—not a mathematical equality test. It binds the name on the left to the result/value on the right.

Follow the name

points = 10
points→10 · int
The name points is currently bound to integer object 10.

Assignment is an expression of binding

Evaluate the right side

Python first evaluates the value/expression on the right of the assignment.

Bind the left name

The name is made to refer to the resulting object.

Reassignment

Assigning a different value makes the name refer to a different object; it does not change the old object itself.

02 · Naming rules

Names should be valid
and meaningful.

Choose names that describe the data. Python identifiers are case-sensitive and cannot begin with a digit or contain spaces.

Try a variable name

Type a name to check its rules.

Quick rules

  • May contain letters, digits, and underscores.
  • Cannot start with a digit.
  • No spaces or hyphens.
  • Case matters: age and Age are different names.
  • Keywords such as class, if, and True cannot be used as ordinary variable names.
user_age = 19 # good
userAge = 19 # valid
2users = 19 # invalid
user-age = 19 # invalid
03 · Data types

Different kinds of
data, different behavior.

A type tells Python what kind of object it is and which operations make sense. Use type(value) to inspect an object’s type.

int
count = 7

Whole numbers, positive, negative, or zero.

float
price = 2.75

Numbers with a fractional component.

str
name = "Ali"

Text inside quotes; strings are sequences of characters.

bool
active = True

Logical values: True or False.

list
items = [2, "x"]

Ordered collection; can be changed and can contain mixed types.

tuple
point = (3, 4)

Ordered collection that cannot be reassigned item-by-item.

dict
user = {"name":"Ali"}

Stores key–value pairs for lookups by key.

set
tags = {"a", "b"}

Collection of unique elements; no duplicate values.

NoneType
result = None

Represents the absence of a value or a placeholder result.

04 · Mutable vs immutable

Can the object change
without rebinding?

Mutable objects can be changed in place. Immutable objects cannot have their contents changed after creation; operations that appear to change them create/refer to a new object instead.

Mutable: list

items = [1, 2]
items→[1, 2]
Appending changes the same list object.

Immutable: string

word = "cat"
word→"cat"
A new string is assigned; the original string itself is not modified.
This distinction matters when two names refer to the same list: editing that list is visible through both names. Rebinding one name alone does not rebind the other.
05 · Type conversion

Convert deliberately.

Type conversion (casting) creates or returns a value of another type when conversion is supported. Conversion is not always the same as formatting or parsing.

Common conversions

ExpressionResult
int("12")12
float("3.5")3.5
str(25)"25"
list("abc")['a', 'b', 'c']
bool(0)False
bool("False")True — non-empty text is truthy

06 · User input

Input arrives as text.

The built-in input() function reads what a user types and returns a string (str), even if the text looks like a number. Convert it if numeric calculations are intended.

Without conversion

age = input("Age? ")
# age is a str
Type something and see the resulting type.

With conversion

age = int(input("Age? "))
next_year = age + 1

For numeric input, validate and convert the text (for example, with int() or float()). If it cannot be converted, Python raises a ValueError.

In a real program, prompt text and error handling make input clearer. Never assume user-entered text is automatically numeric.

08 · Quick recap

Keep these ideas
in your toolkit.

Core concepts

  • A variable name refers to an object.
  • Objects have values and types.
  • = binds/rebinds a name.
  • Use descriptive, valid identifiers.
  • Mutable objects can change in place; immutable objects cannot.
  • Use conversions when the type you have differs from the type you need.
  • input() returns text.
